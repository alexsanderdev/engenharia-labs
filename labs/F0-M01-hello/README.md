# F0-M01 — Hello Lab

**Módulo:** Setup Profissional (Fase 0)
**Tempo:** 15 minutos

Valida o ambiente: SDK, IDE, execução de testes e pipeline.

```bash
dotnet test labs/F0-M01-hello
```

1. Rode os testes e veja-os falhar.
2. Implemente `Saudacao.Para` em `src/F0M01.Hello/Saudacao.cs`.
3. Rode de novo até ficar tudo verde. **Não altere os testes.**
4. Faça commit e push e veja o GitHub Actions ficar verde (ou vermelho, se algum lab estiver incompleto — isso é esperado na `main`).
